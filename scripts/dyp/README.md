# Scripts de Dynamo (dyp)

Carpeta destino para los scripts de Dynamo (`.dyn`) usados en la validación paramétrica de modelos (Fase 1 y 3 del pipeline BIM de Macoia: auditoría de cumplimiento POT/NSR-10 y validación de cotas/aislamientos entre predios colindantes).

Aún no hay scripts publicados aquí — el trabajo de automatización actual vive principalmente en `scripts/pyrevit/` (pyRevit/IronPython) y en el mecanismo de auditoría IFC descrito en `bim-standards/ifc-mapping/` y `projects/csc01-casa-sancarlos/reportes-validacion/`. Cuando se desarrollen grafos de Dynamo (por ejemplo para automatizar validaciones que hoy se hacen leyendo parámetros vía `rvt-mcp`), publicarlos aquí con un nombre descriptivo y una nota de qué validación resuelven.
