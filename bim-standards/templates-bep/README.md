# Plan de Ejecución BIM (BEP) — ISO 19650

Carpeta destino para las guías y plantillas del Plan de Ejecución BIM de Macoia, alineadas con ISO 19650 y el Entorno Común de Datos (CDE) estricto que sostiene la estrategia de "cero rechazos ante las curadurías".

Aún no hay una plantilla de BEP publicada aquí. Cuando se formalice, debe cubrir como mínimo:

- Roles y responsabilidades BIM (incluyendo el rol de auditoría/validación automática de cumplimiento normativo).
- Estructura del CDE (carpetas WIP / Shared / Published / Archive) y su equivalente en este repositorio y en el Drive del estudio (`G:\Mi unidad\00. Macoia\...`).
- LOD/LOIN objetivo por fase, coherente con el uso dual de la plantilla: (1) licencias gestionadas por Macoia desde cero, y (2) auditoría de modelos de terceros.
- Convención de nombres de archivo, de Mark y de Familia/Tipo (ver `bim-standards/shared-parameters/README.md`).
- Puntos de control de calidad (QA/QC) previos a la radicación ante la curaduría.
