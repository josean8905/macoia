## Cómo se versionan estas guías

1. Cada guía lleva en su encabezado YAML `version` (SemVer) y `fecha`, y al final una tabla **Control de versiones**.
2. Todo cambio en la plantilla o en la base de datos que afecte un tipo **debe** reflejarse en su guía en el mismo momento.
3. El commit usa el formato `docs(<elemento>): vX.Y.Z – <resumen>`; el historial de GitHub del archivo es el registro oficial de versiones.
4. Esta tabla de índice se actualiza con la versión vigente de cada guía.
