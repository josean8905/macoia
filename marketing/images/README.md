# Imágenes promocionales

Carpeta destino para las imágenes promocionales y piezas cuadradas (formato WhatsApp/Instagram) referenciadas en `manual-envio-piezas.md` y `macoia-marketing-pack.md`.

Las piezas actuales se producen en Canva (ver referencia de las 4 piezas propietarios/apoderados). Cuando se exporten en definitivo, colocarlas aquí con nombres descriptivos (ej. `pieza-antes-modelo-despues.png`) y actualizar las referencias en los documentos de `marketing/`.
